# Historical parallelisation proposals

The six documents in this directory were written in July 2026 and moved here from root `PARALLELISATION/` on 5 October 2026. Their contents are preserved as the original development record. Start with [INDEX.md](INDEX.md) to navigate the guides.

Treat their diagnoses, code locations, timing estimates and proposed refactors as historical. The RNG and threading code has changed since they were written. Check current code and the authoritative [TODO.md](../../TODO.md) before acting on a recommendation; this directory is not a statement that the proposed parallelisation has been implemented or that its old bug descriptions remain current.

Relative links among the six original documents still work. Commands and source-file paths inside them generally assume the repository root as the working directory. The directory is tracked for reference and excluded from the R package build and website through the enclosing `dev/` rules.
