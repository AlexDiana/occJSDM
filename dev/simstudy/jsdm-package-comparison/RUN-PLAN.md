# Four-package pilot fitting plan

Declared 22 September 2026 before generating data or fitting the pilot. Executes the accepted DESIGN.md. This is one new community, not a repeated-community benchmark. No ecological error threshold or general package ranking is intended.

## Frozen data and environment

Use seed 26092201 for 100 training and 300 independent test sites, ten species, two independent standard-normal environmental predictors and two independent standard-normal site factors. The complete ecological coefficient table is specified in simulate-pilot.R before any data are drawn. Generate with a logit link in raw environmental units. Centre and scale predictors using training sites only, including the saved transformation of true coefficients. Save training-only input separately from truth. Fitting and convergence scripts must not read truth or test responses. Prediction checks use a fixed environmental grid, independent of test outcomes.

Use the isolated lesson-n-environment-20260922 library and launcher. occJSDM main is frozen at 3a9726760f692ffe0ef21ca125d0c7acd02c7532, updating the earlier design's intended revision because this is the already verified setup snapshot. Package code changes between the old intended baseline and this snapshot are recorded in the environment provenance. sjSDM uses fork v0.2.1, PyTorch CPU, no Mojo upgrade. All fitting processes use one computational thread where controlled.

## Budgets and decision rules

- occJSDM and Hmsc: four chains, 2,000 warm-up iterations and 4,000 retained draws per chain, no thinning. Seeds 26092211 and 26092221 respectively. If identifiable coefficient, residual covariance, or fixed-grid marginal-probability diagnostics fail Rhat <= 1.01 or bulk/tail ESS >= 400, perform one longer attempt with 8,000 warm-up and 16,000 retained draws per chain, seeds 26092311 and 26092321. Keep both attempts. Evaluate all coefficients, all species residual variances/covariances, and all ten species at five fixed predictor locations. Raw factor axes are not convergence targets because they can rotate. Inspect sampled-site probabilities too before claiming that target is ready. Passing these checks does not prove convergence or accuracy.
- gllvm: three separate EVA binomial-logit fits with two unconstrained factors; seeds 26092231:26092233, random starting latent scores, one initialisation per fit, standard 6,000 optimisation limits, no standard errors. Preserve objective, convergence flag and maximum absolute gradient where accessible. Choose the converged run with highest EVA objective, never the closest to truth. If convergence fails or repeated converged optima differ by > 0.1 log-likelihood units, allow three additional starts with 12,000 limits, seeds 26092331:26092333. Inspect prediction differences as well. The EVA objective is not directly comparable with the other packages' likelihoods.
- sjSDM: three separate linear logit fits, df = 2, explicit zero environmental/covariance penalty, RMSprop with zero weight decay, learning rate 0.005, full batch of 100 sites, 1,000 Monte Carlo draws and 1,000 epochs. Seeds 26092241:26092243. No automatic early stopping. Save histories and full numeric parameters. Evaluate the same integrated training likelihood for all starts with checked two-dimensional Gaussian quadrature, separately from the noisy native objective. If late loss histories are still improving, checked objectives differ by > 0.1, or fixed-grid marginal predictions differ by > 1 percentage point, allow a second set of three fresh fits with 3,000 epochs, 2,000 integration draws, learning rate 0.002, seeds 26092341:26092343. Preserve failures. Select only by checked training likelihood; unresolved instability remains a finding. A lower-rate diagnostic polish using saved starts may be reported separately if necessary, never silently replacing this budget.

## Comparable extraction and evidence

Verify identical ordered X/Y input, ten species and two factors, absence of extra information, and actual backend/link/method. For Hmsc disable additional X scaling because the shared input is already standardised. For occJSDM explicitly account for its internal standardisation. Preserve default Bayesian priors and record their coefficient hierarchy. No prior or regularisation tuning against truth.

Primary common prediction target: a new site's occurrence probability, averaged over normally distributed hidden conditions. Use the analytic probit-normal mean for Hmsc and checked one-dimensional integration for logit fits, within each Bayesian draw before posterior averaging. Verify integration changes by < 0.0001 probability (0.01 percentage points); refine numerical integration without altering fitted models. Compare with package zero-factor predictions only as an implementation check, not as the marginal target. Reconstruct sampled-site predictions from paired Bayesian draws or checked joint conditional integration for optimised fits if feasible; otherwise label that comparison pending.

Archive every attempt, warnings, timing, session information, complete settings, ordered input hashes and numeric parameters sufficient to reproduce extraction in fresh R. Full fits remain outside Git; commit compact scripts and results only when requested. Score truth only after fitting decisions and diagnostics are saved. Report any unresolved convergence beside provisional error summaries. Recompute summaries independently from the saved prediction table.

## Execution rulings, before truth scoring

- All six gllvm EVA starts report convergence but give very different objectives and extreme environmental coefficients/residual scales. The initial method is unsuitable for this pilot as fitted. The installed 2.0.15 method/link registry explicitly supports **VA with binomial logit**, in addition to EVA and LA. Run three VA starts with the same data, family, factor count and 6,000 limits, seeds 26092231:26092233. This changes the fitting approximation only. Apply the same second-attempt rule if needed; keep EVA failures visible. Choose no method using generating truth or test outcomes.
- occJSDM's optional latent-trait array has shape species by zero factors, not zero by species. Correct the study assertion to check its second dimension. No model fit changes.
- sjSDM's native `type = "raw"` output still applies the stabilising affine transformation `0.999999 * mu + 0.0000005`. Reconstruct the linear predictor from numeric weights and check against that exact transformation. Do not use the transformed native output as an unmodified predictor. The fitting likelihood uses the corresponding transformation on probabilities. This is documented study handling, not a package fix.
- The first sjSDM starts agree within 0.57 percentage points on the fixed grid and within 0.03 integrated log-likelihood units. Two late loss histories still have small downward trends. Run the predeclared second attempt conservatively, without claiming these noisy trends prove non-convergence.
- Six random-start VA fits give finite gllvm estimates but several have poor gradients or settle at nearly zero factor variance. Before declaring gllvm unusable, test its documented residual-based initialisation (`starting.val = "res"`) with `jitter.var = 0.1`, three seeds 26092331:26092333 and the same 12,000 iteration limit. This is an additional, explicitly recorded diagnostic budget prompted only by fitting evidence. Preserve the random-start results. Do not change the model, priors, link, dataset or fit selection criterion.
- A native Hmsc prediction check using exactly one posterior draw hit an upstream singleton-dimension error. Repeating that draw twice makes the native comparison well-defined; the two identical predictions match the independent paired-draw reconstruction. No fitted model was changed.
- The fit driver was edited to add gllvm initialisation arguments while three longer sjSDM processes were running. Each worker finished fitting and saved its numeric fit and success record, then reported a trailing R parser error because the open script's offsets had changed. Preserve these process errors and all logs. Accept the saved fits only after fresh-process parameter, input, numerical-integration and convergence checks; do not describe these three process exits as clean. Future long runs must execute an immutable copied driver or parse the entire driver with `source()` before execution. This execution mistake does not justify discarding a fit and drawing a more favourable replacement.
- Selection adds an explicit maximum absolute gradient < 0.01 screen for gllvm's nominally converged runs, prompted by the observed large gradients. The best objective is chosen among the remaining VA fits. This criterion was applied before any truth errors were computed. The strongest VA solution was independently reproduced; lesser local optima remain in the report.
