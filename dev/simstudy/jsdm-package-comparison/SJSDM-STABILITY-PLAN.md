# sjSDM stability follow-up

Authorised by Doug's “continue” after the four-package pilot report. This follow-up uses the existing training data and the three saved longer sjSDM fits. The pilot's truth errors are already known, so this is explicitly a diagnostic follow-up, not a new experiment claimed to have been designed before seeing any results. No test outcomes or generating parameters are read by these scripts. All scientific model choices remain fixed: logit, linear environment, two factors, no penalties, no extra data, PyTorch CPU.

## Questions and bounded work

1. At each saved fit, calculate the integrated training likelihood and its derivative using deterministic quadrature. Check the derivative against finite differences and a finer quadrature rule. This distinguishes failure to reach a stationary fit from harmless rounded/noisy reporting. The native training history is rounded to three decimals per site, while native final `logLik()` defaults to only 100 integration samples. Neither is sufficient for the 0.1 total-log-likelihood stability rule.
2. If the derivatives or trajectory show remaining movement, continue each saved fit through the native PyTorch sjSDM fitter with a lower learning rate. Start with a single controlled change: 1,500 additional epochs, learning rate 0.0002 rather than 0.002, the same 2,000 integration draws and full batch of 100 sites. Seeds 26092441:26092443. Reset the optimiser because its moment state was not saved; verify that the optimiser references the restored parameters. Save a checkpoint every 300 epochs, with precise deterministic likelihood and gradient checks outside training.
3. If a stable gap remains, use the diagnostic evidence to choose one further bounded experiment before running it, recording its budget here. Do not repeatedly extend fits without a stated question. Any deterministic optimisation is a separately labelled diagnostic reference, not silently substituted for a package fit.

Keep the original stability criteria: repeated-fit integrated log-likelihood spread <= 0.1 and maximum marginal probability spread <= 1 percentage point on the pre-existing five-point environmental grid. Also inspect gradients and improvement through checkpoints. These are computational checks, not ecological accuracy targets. A shared flat-looking history is not proof of convergence or a global optimum.

Never overwrite the original pilot fits, selection, probability tables or logs. Save the follow-up under `stability/`; if fits become suitable for a revised comparison, create a separately versioned selection and export before updating the report. Execute immutable copied scripts using `source()` so an edit cannot affect a running R parser.

## Second experiment: deterministic reference

The lower-step fits finish cleanly and retain separated likelihoods, with only small gains through 1,500 extra epochs. To distinguish slow/noisy optimisation from an unsuitable likelihood surface, run three **diagnostic reference** fits from those endpoints. Use the same two-factor joint likelihood and its analytically differentiated 81-node-per-factor quadrature, checked against finite differences first; BFGS, at most 250 iterations, relative tolerance 1e-10. Check endpoints independently at 161 and 241 nodes before interpreting their scores or gradients. If those checks disagree, the reference is numerically inadequate and must be reported as such. Retain all endpoints and trajectories. These are not native package fits and will not silently replace sjSDM in the package comparison. No truth error is scored during this diagnosis.

## Accurate scale profile after rejecting the reference

The deterministic reference fits are **rejected**, despite their optimiser convergence flags: factor contributions grew to thousands or more, and 81/161/241-node likelihood estimates disagree materially. Fixed quadrature can be exploited when a logistic transition becomes sharper than its nodes can resolve. Those apparent improvements are not evidence of better fits.

To determine whether large scales are attractive to the actual likelihood, profile the two largest residual-scale species in the best native endpoint (species 2 and 7), multiplying that species' intercept, both environmental slopes and both factor loadings together by 0.5, 1, 2, 4, 8 and 16. Hold every other parameter fixed. Rotate the factors so the focal species depends on only the first factor, then integrate that factor adaptively with explicit breakpoints at its logistic transition. Use 61 and 121 Gaussian nodes for the second factor and require total-log-likelihood agreement < 0.001, with the scale-one value matching the independently checked original likelihood. This is a diagnostic profile, not refitting or a package replacement. No truth or test data are involved.

## Separate sensitivity fit using the package's default weak penalty

The accurate profile rules out interpreting the coarse-reference gains as real gains. It also shows weak scale information: for species 2, scaling all effects by 16 worsens the checked training log likelihood by only 0.084. Smaller steps alone did not settle the original fit. Test a **separate regularised arm**, restoring `RMSprop(weight_decay = 0.0001)`, the default exposed by this sjSDM release. This is a model/estimation change and must be labelled, not substituted silently for the unpenalised baseline.

Use the same three seeds as the original longer fits (26092341:26092343), 3,000 epochs, 2,000 integration draws, learning rate 0.002, full batch, no scheduler or early stopping. Everything except weight decay is unchanged from that earlier attempt. For stability compare the precise **penalised** objective: total negative log likelihood plus `100 * 0.0001 / 2 * sum(beta^2 + loading^2)`. The factor of 100 converts the package's mean site loss to a total. Confirm the penalty gradient as well as its value. Keep environmental/covariance lambda penalties zero. Require repeated objective spread <= 0.1 and fixed-grid probability spread <= 1 percentage point, with verified numerical integration. If only endpoint jitter remains, allow one 1,000-epoch continuation at learning rate 0.0002, with other settings unchanged, from all three endpoints. No truth errors are inspected until this arm's diagnostics and choice are saved.

## Curvature at the two stationary solutions, and the multistart experiment

Curvature was checked at all three penalised-reference endpoints with `sjsdm-curvature.R`: the Hessian of the penalised negative log likelihood by central differences of the analytic 121-node gradient, repeated at 161 nodes, with the factor-rotation generator identified first. Every endpoint has exactly one eigenvalue within 1e-6 of zero, and its eigenvector coincides with the rotation direction to machine precision. All 49 remaining eigenvalues are positive, between about 0.04 and 20.6, identical at 121 and 161 nodes. Both stationary solutions are therefore genuine local maxima; neither is a saddle. Starts 2 and 3 are the same solution after a factor rotation, agreeing to 1e-5 in every coefficient and in the implied species covariance. Along the straight path between the two solutions, after aligning their factors, the penalised score falls to 484.68 below zero at 45% of the way, 0.25 below the lower endpoint: the solutions sit in separate basins about 4.3 parameter units apart. They differ almost entirely in species 2 and species 9: solution A (score about -484.30) gives species 2 a residual SD of 3.3 and species 9 of 1.0, while solution B (about -484.43) gives species 2 a residual SD of 1.1 and species 9 of 3.1. The compact records are `curvature-summary.csv`, `path-profile.csv` and `species-differences.csv` under `stability-resolution-results/`.

The original repeated-fit spread criterion assumed one optimum. With two genuine optima, the recorded assessment becomes: (1) how often independent native starts reach each basin; (2) whether native endpoints within the best basin agree to within 0.1 in penalised score and within 1 percentage point on the fixed prediction grid; (3) whether the best basin is reached by at least two independent starts. The declared selection rule is the native endpoint with the highest precise penalised training objective, accepted only if its basin satisfies (2) and (3). Inferior-basin fits stay in the record. No truth or test data enter any of this.

Budget, stated before execution: nine fresh native sjSDM starts, indices 4 to 12, with the unchanged weak-penalty configuration (3,000 epochs, learning rate 0.002, 2,000 integration draws, full batch of 100, RMSprop weight decay 0.0001, seeds 26092804 to 26092812), each followed by the unchanged 1,000-epoch continuation at learning rate 0.0002 with a fresh optimiser (seeds 26092904 to 26092912). Each start took about 6 minutes previously; the nine run as separate single-threaded processes. Endpoints are classified by deterministic BFGS refinement at 81 nodes, checked at 161 and 241 nodes, and matched to solution A or B by aligned parameter distance below 0.05. Scripts: `sjsdm-multistart.R` and `check-sjsdm-multistart.R`. Outputs go under `stability-resolution/multistart/`; nothing earlier is overwritten. If the best basin is reached only once, no selection is accepted and the next step is decided from that evidence rather than by extending runs.
