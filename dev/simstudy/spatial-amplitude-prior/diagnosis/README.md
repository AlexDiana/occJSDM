# Conditional diagnosis of spatial-field recovery

This investigation answers Doug's request to diagnose poor spatial recovery while the separate half-Cauchy comparison is running. It reuses the same nine saved binary communities. The earlier [rare-species diagnosis](../../spatial-targeted-recheck/diagnosis/REPORT.md) remains the evidence for occupancy-intercept shrinkage; this investigation concerns recovery of the spatial field itself.

The [protocol](PLAN.md) defines four conditional comparisons. The original prior comparison, its finite longer-run schedule and its two-stage extension rule are unchanged. No package default or production sampler is changed here.

The independent sampler uses [elliptical slice sampling](https://proceedings.mlr.press/v9/murray10a.html) with the package-matched, full-support Gaussian covariance. Every species is independent once the shared amplitude/range and specified coefficients are fixed, so separate species calculations target the stated conditional posterior exactly, subject to Monte Carlo error. Configuration C jointly samples the species intercept and field under independent Gaussian priors. Configuration D adds independent ecological occupancy states, not repeated detections of the same latent state.

From the repository root, set `REPO` to this checkout and `STUDY` to the raw spatial-amplitude archive. Run `check.R REPO STUDY/diagnosis-v1` first. Then use `run.R REPO STUDY pilot 2` for the two predetermined timing cases or `run.R REPO STUDY all 2` for the complete conditional comparison. Existing exact-source results are verified and reused. `analyse.R REPO STUDY/diagnosis-v1 2` audits all selected posteriors and produces pooled community summaries; `plot.R REPO STUDY/diagnosis-v1` creates figures and exports compact evidence to `results/`. All scripts are under `dev/simstudy/spatial-amplitude-prior/diagnosis/` and are run with `Rscript`.

The covariance is independently reconstructed from the generating coordinates and the package's kernel regularization, then checked against native and independent package bases. Validation compares the sampler with deterministic logistic-normal quadrature, separate field/intercept moments, a Gaussian contrast, a correlated Gaussian target and exact seed reproducibility. Initial pilot outputs before the added probability-mean ESS screen remain archived in `pilot-before-mean-ess/`; their selected replacements use the final rules.

The full results and diagnostics are retained locally in `dev/simstudy/results/spatial-amplitude-20260928/diagnosis-v1/`. Compact tables and figures support the final report, while the raw archive preserves draws, initial and selected schedules, source/input hashes and seeds. Inspect all unresolved convergence flags before interpreting conditional recovery differences. These comparisons do not establish nominal coverage, isolate every unknown parameter, or provide an additive decomposition of full-model errors.

The analysis also reports a descriptive envelope over the four existing chains for each independently fitted species. It sums species-wise minimum/maximum squared errors before computing community RMSE, so arbitrary chain numbering cannot change the bounds. Occupancy MAE uses absolute-error sums. These observed-chain envelopes do not constitute Monte Carlo confidence bounds, and the pooled-chain estimate need not lie inside them. They do not clear any convergence flag or trigger new fits.
