# Factor correlation reparameterisation validation

**Status: ALEX TO REVIEW, 11 September 2026.** This change addresses the residual species correlation item in `TODO.md`. The comparison starts from `90026d6`, which already includes collection covariate alignment. It changes post-processing, leaving the MCMC updates unchanged.

**Cause and estimand.** The fitted model's site score prior is normal with covariance `sigma_h^2 I`: see `sample_U_cpp()` in `src/jsdm.cpp`. Conditional on a parameter draw, the residual factor covariance across species is therefore `sigma_h^2 crossprod(L)`. The scalar cancels in the correlation matrix, so `returnCorrelationMatrixOutput()` correctly targets `cov2cor(crossprod(L))`. This is the model covariance of a new site's latent factor contribution. It is not the empirical covariance of the finite set of fitted site scores, and it does not include independent observation noise in the continuous response model.

The old helper forms `Q2 = Q D`, where `Q` is orthogonal and `D` contains the diagonal entries of the QR factor `R`. It stores `U* = U Q D` and `L* = D^-1 Q' L`. Their product is unchanged, but the stored loading Gram matrix becomes `L' Q D^-2 Q' L`. Unequal factor scales survive species normalization and can change correlation signs. For the deterministic regression fixture, species pair 2,3 changes from `1/sqrt(10)` to `-1/sqrt(10)`. With one factor the old magnitude division preserves defined correlations, but still changes covariance and new-site predictive variation; a zero anchor also causes nonfinite values.

**Change.** `reparamFactorModel()` in `R/jsdmfun.R` now uses a complete orthogonal QR matrix with diagonal signs only. Writing that rotation/reflection as `H`, the stored draws are `U* = U H` and `L* = H' L`. Since `H H' = I`, both `U* L* = U L` and `crossprod(L*) = crossprod(L)` hold for each draw. Score norms are preserved too, so the stored `sigma_h` retains its original meaning. The one-factor case reflects the first nonzero loading positively and otherwise leaves magnitudes alone; an all-zero loading vector leaves the scores unchanged. Complete QR handles rectangular loading matrices. Zero diagonals are never inverted, and multiplication by the original loading matrix preserves species order when QR pivots columns.

**Consumers audited.** Both final `runOccJSDM()` call sites use this helper: `U`/`L` for site factors and `A`/`C` for latent traits. Their products stay unchanged. Environmental trait effects, fitted linear predictors and variance partitioning therefore keep the sampled values. The correlation output needs no separate adjustment. `predictNewSites()` passes the stored loadings and scalar `sigmah_output` to `computeNewOutputs()` in `src/jsdm.cpp`, which draws new scores with covariance `sigma_h^2 I`; an orthogonal transform preserves that predictive distribution. This public function reports species marginal quantiles, so the regression test checks their analytically known normal quantiles, not a joint predictive simulation that the API does not return. Ordination scores and loading magnitudes now share the same orthogonal coordinate system. `plotBiplot()` and its help no longer say loading magnitudes are fixed to one.

**Regression evidence.** A fresh baseline full suite passed. The new file `tests/testthat/test-factor-reparameterisation.R` then failed against the old helper for magnitude normalization, covariance/correlation changes, zero anchors and prediction scale. After the change its 235 expectations pass. Tests cover one and multiple factors, mixed signs, unequal scales, multiple iterations/chains, a pivoted zero column, rank deficiency, all-zero loadings, more factors than loading columns, one site and no factors. A real fit is intercepted only at the final helper boundary to compare raw and stored `U`/`L` and `A`/`C` draws; the actual helper still runs. The test also exercises public correlation, ordination, loading, biplot and prediction outputs. The full suite passes with the same two expected skips as baseline: the opt-in coverage grid and the already documented multi-thread reproducibility gap. The only test-run warning is that the installed testthat package was built under R 4.5.2.

**Recovery design.** `validate_factor_correlations.R` generates three independent continuous datasets with 500 sites and three binary datasets with 1,000 sites. Each has six species, two factors, one standardized environmental covariate, nonzero intercepts and slopes, and no spatial field. The loading matrix is specified explicitly to avoid the default simulator's sparse, boundary-valued correlations. Its 15 off-diagonal truths range from -0.9487 to +0.9487, and none is zero or exactly plus/minus one. Responses follow the same generative equations as `simulateData()`: independent normal scores with `sigma_h = 1`, a continuous observation standard deviation of 0.5, or Bernoulli draws with logistic probabilities. Each fit uses two chains, 1,000 burn-in and 1,000 retained iterations per chain, with one TBB/OpenMP thread. Each dataset is fitted once. The script captures the actual pre-reparameterisation draws, applies the old helper from the baseline commit to them, and compares those outputs with the stored corrected fit and raw-draw reference. The three versions therefore share all data and sampler draws exactly.

**Recovery results.** Aggregating 15 pairs over three datasets per model, with equal dataset weights:

- Continuous: mean absolute error falls from 0.2473 to 0.0205 and RMSE from 0.3065 to 0.0307. Signed bias changes from -0.0295 to +0.0022. Correct signs increase from 39/45 to 45/45. Mean 95% interval width is 0.1082 after correction (0.0820 before).
- Binary: mean absolute error falls from 0.1793 to 0.0541 and RMSE from 0.2283 to 0.0750. Signed bias changes from -0.0180 to +0.0082. Correct signs increase from 41/45 to 44/45. Mean interval width is 0.2917 after correction (0.3888 before).
- Corrected estimates and intervals match the raw-draw reference. Across all 12,000 retained parameter draws, the largest absolute difference is `7.11e-15` for the factor contribution, `8.88e-15` for the loading covariance, and `6.66e-16` for the correlation. The old transform also preserves the factor contribution, but changes individual covariance entries by as much as 14.31 and correlations by 1.118. These intervals are much narrower than the full correlation range, so this is not the withdrawn boundary-coverage statistic.

**Limits.** This establishes and removes an algebraic distortion of the sampled output. Three datasets per model are a focused point-recovery diagnostic, not a nominal interval coverage study or evidence that all remaining sampler biases have been resolved. Some factor coordinates and scale parameters still produce convergence/ESS warnings in these short fits; the error comparison does not establish overall chain convergence. Binary correlations retain more uncertainty than continuous correlations. Spatial models, two-stage detection and uncertainty calibration still require their own validation. Previously saved fits have already discarded the diagonal normalization scales; applying the new helper to those stored arrays cannot reconstruct their original covariance. Refit them, or use retained raw pre-reparameterisation draws if available.
