# A slab for the embedding scales: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cap the prior standard deviation of every coefficient part of an embedding row at `slab_scale` (default 2), so that the grouped prior loses its wide upper tail and keeps its body.

**Architecture:** One new setting read by `read_coef_prior()`. `coef_prior_sds()` returns capped standard deviations, which carries the cap into every coefficient draw with no change to C++. With a finite cap the draws of `sigma_emb` and the axis scales become slice draws, and the axis and `sigma_emb` moves scale each part by the ratio of its own prior standard deviations. With an infinite cap every function takes its present path and draws the numbers it draws at a03a1b8. The default stays `Inf` until Task 5, so the suite stays green while the pieces are built.

**Tech Stack:** Base R, roxygen2 8.1.0, testthat edition 3, coda (already a dependency) in the study scripts.

**Spec:** `dev/superpowers/specs/2026-11-25-axis-slab-design.md`. Read it first, in particular "Mathematics", "Where it goes", "Tests" and "Evidence before it is kept". This plan does not repeat the formulas or the reading rules.

# Design: dev/superpowers/specs/2026-11-25-axis-slab-design.md.

test_that("the capped standard deviations follow the design's formulas", {
  x <- axis_move_state(); cp <- x$cp; cp$slab_scale <- 0.8; emb <- 3:5
  sds <- occJSDM:::coef_prior_sds(cp, x$sigma_b, x$sigma_emb, x$lambda, 2L, 5L)
  lt <- 1 / sqrt(1 / x$lambda[emb]^2 + 1 / 0.8^2)
  om <- 1 / sqrt(1 / (x$sigma_emb * x$lambda[emb])^2 + 1 / 0.8^2)
  expect_equal(sds$b, c(rep(x$sigma_b, 2), om))
  expect_equal(sds$g, matrix(c(1, 1, lt), 2L, 5L, byrow = TRUE))
  expect_equal(sds$c, cp$c_base * c(1, 1, lt))

  expect_equal(eff$axis, c(1, 1, lt)); expect_equal(eff$leftover, c(NA, NA, om))
})

test_that("an infinite cap, or a record without one, gives the present standard deviations exactly", {
  x <- axis_move_state()

  x <- axis_move_state(); x$cp$slab_scale <- 0.8

For column k the expected proposal multiplies `G[, k]` and `C[, k]` by `rho_g` and the leftovers by `rho_e`, and the Jacobian term replaces `m * delta[j]`:

```r
eff0 <- occJSDM:::coef_effective_scales(want$cp, want$sigma_emb, want$lambda)
prop$lambda[k] <- want$lambda[k] * exp(delta[j])
eff1 <- occJSDM:::coef_effective_scales(prop$cp, prop$sigma_emb, prop$lambda)
rho_g <- eff1$axis[k] / eff0$axis[k]; rho_e <- eff1$leftover[k] / eff0$leftover[k]

prop$B <- t(want$Tr_b %*% prop$G + want$A %*% prop$C + R)
