# occJSDM assistant pilot

This optional folder contains the occJSDM assistant pilot and its Paper2MCP conversion workspace. The four tools are `validate_data`, `fit_model`, `diagnostics` and `summarise_fit`. The server entry point is `paper2agent/src/occJSDM_mcp.py`; its R dispatcher calls the existing package. The local pilot passed independent verification and real stdio acceptance. Cloud deployment remains pending.

Paper2Agent is installed on the local build host at revision `8c2d059165ef8cdcb70dbea76655b9c2b55b38e6`. The scientific source is pinned to `b7b7001e56cea8e3931b09c917ea0e29e6cef3c6`. Setup and reference gates passed: 107 native comparisons, including different model types, row identities and settings. The final independent suite passed 37 tests and reran 18 saved native reference cases with exact comparisons of complete fits and tables. All 19 stdio acceptance cases passed in both development and fresh Python/R runtimes. The separate R restore used recorded dependency archives and rebuilt occJSDM from retained source, checking lock versions on macOS arm64 R 4.5. These checks do not establish Linux/Posit Cloud compatibility or beta statistical calibration.

Use [the server setup and usage guide](paper2agent/USAGE.md) for the tools, artifact locations, native runtime and proposed Cloud handoff. The source archive, environments and generated references are local ignored build payloads; copying only tracked server files does not install the native package. Cloud registration, controlled model comparison and workshop adoption remain pending. Doug already completed an unscored direct-R smoke test in Cloud; see [the evidence record](paper2agent/reports/cloud-smoke-test.json).

Start with [the model trial guide](paper2agent/class/model-trial.md). [The installation script](paper2agent/tests/data/install-reference.R) installs this checkout into a separate R library and records source and installed-package hashes. [The R preparation script](paper2agent/tests/data/prepare-trial.R) checks that provenance, then uses the existing package and test-fixture simulator to create synthetic trial inputs and native R reference results. Both require `jsonlite` and `digest` for their manifests. R package dependencies are still declared in the package's existing `DESCRIPTION`.

The starter fits use only 20 burn-in and 20 kept iterations. They test execution and recognition of inadequate diagnostics, not reliable ecological inference or workshop readiness.
