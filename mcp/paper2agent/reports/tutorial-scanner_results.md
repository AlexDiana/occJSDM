## Source contracts and checks

- Model inference uses duplicated `Site`, then duplicated `Sample`, and observed OTU type (`R/runOccJSDM.R` 139-234). No repeated Site, or no Site, gives a no-detection-stage JSDM. Repeated Site with no Sample or globally unique Sample gives occupancy. Repeated Sample gives two-stage. Unreplicated count-response data errors; unreplicated noninteger data infers continuous and is outside this pilot. Replicated reads are thresholded before fitting (558-571). Native inference should decide, not a simulator model argument or guessed M/K/P rule.
- Native observation NA is allowed only in two-stage (580-586). Missing site/sample/primer identities error (605-609); missing selected covariates error (620-621). Preserve zero versus missing observations. Check NA independently in binary, occupancy and two-stage fixtures and retain native outcomes. Nonfinite observations need a separate probe because thresholding can otherwise disguise them as detections.
- Occupancy and two-stage fits arrange info by typed Site/Sample/Primer and permute OTU with it (530-545). Canonical collection rows use typed Site+Sample grouping (638-644), avoiding old pasted-key collisions; variable primer subsets and unequal PCR replication are supported (673-730). Row identifiers are metadata and do not substitute for paired info/OTU positions. Reject supplied row identity disagreement without automatic reordering.
- Validate occupancy covariates are invariant within each Site and collection covariates within each Site+Sample before native preparation, because native preparation picks first values (9-25, 638-644, 748-775). Do not reject `Site` or `Sample` solely for being selected collection covariates: native tests explicitly cover that case. Let native matrix expansion reject unsupported values, preserving factors and covariate names.
- Traits are matched by row names to OTU species names; duplicate traits row names and missing species fail, and native code reorders named trait rows to species order with `drop=FALSE` (780-809). Absent traits follows the supported zero-trait route. Categorical traits are covered by smoke tests. Check malformed/NA traits and empty trait-table boundaries without silently repairing identities. The pilot may require explicit OTU species names to avoid the native unnamed-species fallback, since the approved contract forbids inventing species identities.
- `create_covariates_matrix` explicitly rejects NA (74), standardizes numeric columns by their empirical mean/SD (108-121), and uses native factor/model.matrix expansion (170). Constant numeric covariates, one-level factors, one-row grouped covariates and zero-column explicitly supplied traits need execution probes for useful error reporting. Do not replace standardization or manufacture an extra factor level.
- MCMC arrays reserve `niter` retained draws (954-1008), and each chain iterates `nburn + niter * nthin` times (1182). Saving occurs only after burn-in at divisible thinning steps (1263-1286). Thus no divisibility restriction between `niter` and `nthin` is justified. The native thinning regression uses niter 10, nthin 2 (`test-regression-bugs.R` 101-111).
- R `set.seed` controls the serial C++ stream through a base seed drawn from R in `setOccJSDMSeed(sample.int(...))` (1014-1024). Current source comments and RNG tests describe serial random sampling with parallel deterministic calculations, superseding the old OpenMP notes. Record actual R/RcppParallel thread settings and establish seed agreement on the tested runtime, without extending the claim to untested OS/libraries.
- `returnConvergenceDiagnostics` covers beta0_psi, beta_psi, beta_theta, p, q and theta0 when present. It does not cover every model/latent block. `runOccJSDM` also invokes `computeDiagnostics` (1456), whose native warning thresholds are Rhat 1.1 and ESS 50; preserve those warnings independently of the stricter classroom screen. Constant chains return Rhat NA in `computeRhat` (148-153); unavailable diagnostics never establish convergence.

## Required execution probes and native limitations

These are source risks needing independent direct R evidence, not claims of reproduced failures.

1. **Binary data with unsorted explicit unique Site IDs.** OTU is not arranged in the binary branch, but `process_covariates` groups/sorts by Site. Covariate/response alignment may differ. Compare an original and paired row permutation with native design/output records. Do not promise arbitrary binary Site order support until this passes. A faithful wrapper can explain/defer the unsupported case rather than silently reorder scientific input or fix the sampler.
2. **Occupancy with local Sample IDs reused across sites.** `inferDataModel` checks Sample duplication globally, not typed Site+Sample duplication. Such an occupancy design can infer two-stage despite only one observation per physical sample; two-stage then needs Primer. Preserve native inference and report the conflict. This differs from the supported reused local IDs in true two-stage alignment fixtures.
3. **niter = 1.** The approved FitOptions lower bound allows one saved draw. `computeRhat` computes chain variance, then evaluates `if(any(variances == 0))` before its tryCatch. With one draw variance is NA, so diagnostics may error rather than return unavailable. Probe direct fitting and postprocessing. Retain the limitation or report diagnostic failure; do not replace native diagnostic formulas. Distinguish successful fitting from successful diagnostics/summary if the native result exists.
4. **Data.frame OTU.** The fit guard's error text says matrix or data.frame, but `inferDataModel` requires `mode(OTU) == "numeric"`; ordinary numeric data.frames have mode list. Use numeric matrix as the verified native RDS contract unless an independently tested I/O conversion is explicitly recorded. Matrix dimensions/species names must remain intact.
5. **Reserved/identifier covariate names.** Native collection Site/Sample selections are supported; Site selected as an occupancy covariate may interact with grouping. Duplicate info column names and a column named rownum can also interact with native temporary columns. Probe rather than broadening a blanket prohibition; only source-backed guards belong in validation.
6. **Small shapes.** Verify one species, one selected covariate, no selected covariates and absent/zero-column traits. Native fitting caps factors at species count and sets d=0 for one species (822-835). Report effective native factor count, rather than claiming the requested count necessarily survives unchanged.
